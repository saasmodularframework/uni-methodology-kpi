# Assignment-03

*Computer Lab Assignment · Stochastic Petri Nets Advanced Modeling*

## Overview & Requirements

Using specialized software for modeling stochastic Petri nets ([CPN IDE](https://cpnide.org/), [Petri-object Simulation](https://github.com/StetsenkoInna/PetriObjModelPaint), or [Renew](http://www.renew.de/)), develop a software model containing **at least 50 events**.
