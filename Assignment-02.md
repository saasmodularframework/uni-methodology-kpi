# Assignment-02

*Computer Lab Assignment · Stochastic Petri Nets Model Development*

## Overview & Software Tools

Using specialized software for modeling stochastic Petri nets (**CPN IDE** [cpnide.org](https://cpnide.org/), **Petri-object Simulation** [GitHub](https://github.com/StetsenkoInna/PetriObjModelPaint), or **Renew** [www.renew.de](http://www.renew.de/)), develop a software model containing **at least 50 events**.

## Implementation Requirements

- **Software Environment:** Choose one or more of the specified stochastic modeling environments.
- **Model Complexity:** Ensure the constructed model incorporates a minimum of **50 events** to accurately simulate complex computational processes.
